# Химлаб 118

Химическая 3D-игра-симулятор. Смешивайте любые из 118 элементов и 40 реактивов и смотрите реакцию: уравнение, тепловой эффект, наблюдения и объяснение.

- **Кампания** — 29 миссий-головоломок в 5 главах, звёзды, подсказки, звания.
- **Коллекция** — 90 проверенных реакций четырёх уровней редкости.
- **Свободная лаборатория** — 3D-стол, переливание реактивов, управление температурой от −30 до 900 °C.

## Как устроена химия

- Уравнения уравниваются расчётом: решается система сохранения атомов и заряда.
- ΔH° считается по закону Гесса из стандартных энтальпий образования (25 °C, NBS/CRC).
- Замещение металлов — по стандартным электродным потенциалам, осадки — по таблице растворимости, бинарные соединения — по степеням окисления и электроотрицательности.
- Температурные пороги — ориентиры учебных сценариев, а не универсальные константы. Темп анимации ограничен; он не является расчётом химической скорости. При сильном нагреве водной среды показано упаривание, высокие значения относятся к режиму нагревателя.
- Каждый ответ помечен источником: «Проверенная реакция», «Выведено по правилам» или «Нет в базе» — игра не выдумывает то, чего не знает.

## Структура

| Путь | Что там |
| --- | --- |
| `src/engine.js` | Химический движок: данные элементов, ΔHf, реакции, правила, температура |
| `src/missions.js` | Главы, миссии кампании, задания дня |
| `src/physics.js` | Материалы, плавучесть, расход реагентов и движение частиц в секундах |
| `src/lab3d.js` | 3D-лаборатория на Three.js |
| `src/lab2d.js` | Запасная 2D-колба, если нет WebGL |
| `src/ui.js`, `src/styles.css`, `src/app.html` | Интерфейс игры |
| `vendor/three.min.js` | Three.js r128 (MIT) |
| `scripts/build.mjs` | Сборка в один файл `dist/index.html` |
| `tests/` | Тесты движка и миссий, браузерные e2e-тесты |

## Команды

```bash
npm ci               # зависимости (нужны только для e2e-тестов)
npm test             # тесты движка и решаемости всех миссий
npm run build        # сборка в dist/
npm start            # сборка и локальный сервер http://127.0.0.1:8080/
npx playwright install chromium
npm run test:e2e     # прохождение всей кампании в браузере
```

## GitHub Actions

- **CI** (`.github/workflows/ci.yml`) — на каждый push и pull request: тесты движка, сборка (артефакт `himlab-118`), затем браузерные тесты в Playwright.
- **Deploy to GitHub Pages** (`.github/workflows/pages.yml`) — на push в `main`: тесты, сборка и публикация `dist/` на GitHub Pages.

Чтобы публикация заработала, один раз включите Pages: **Settings → Pages → Build and deployment → Source: GitHub Actions**.

Прогресс игрока хранится в `localStorage` браузера.

## Обновлённая лаборатория

- Единое оформление в тёмной бирюзовой палитре, этапы опыта и паспорт вещества.
- Процедурные фактуры камня, металла и порошков; волны и мениск жидкости.
- Плавучесть лёгких металлов, тяжёлые капли ртути, постепенное растворение растворимых порошков и оседание осадков. Катализатор не расходуется.
- Движение и количество испускаемых частиц рассчитываются по времени, а не по кадрам.
- Управление камерой мышью, одним/двумя пальцами и клавиатурой (стрелки, +/−, Home); возврат камеры, пауза после переливания, облегчённая графика.
- Результаты на телефоне располагаются над сценой и не закрывают колбу.

### Границы научной модели

У игры нет заданных масс, концентраций, давления и системы количественного равновесия. Парные реакции в смеси из трёх веществ не являются расчётом конечного состава. ΔH° приведён для записанного уравнения при стандартных состояниях и 25 °C, а не для фактического нагрева колбы. Порог замерзания раствора −7 °C задан условно: температура зависит от состава и концентрации. Объём, цвет, время растворения, движение и расход твёрдых образцов иллюстративны. Данные плотности некоторых металлов используются только для отличия плавания от оседания в водной среде.

Кислород и водород бесцветны. В разложении 3 % H₂O₂ с MnO₂ или KI показываются пузырьки, а не высокая пена: для устойчивой пены требуется ПАВ. Для концентрированной серной кислоты не применяется модель кипения/замерзания воды.
