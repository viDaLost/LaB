# Химлаб 118

Химическая 3D-игра-симулятор. Смешивайте любые из 118 элементов и 61 реагента и смотрите реакцию: уравнение, тепловой эффект, наблюдения и объяснение.

- **Кампания** — 29 миссий-головоломок в 5 главах, звёзды, подсказки, звания.
- **Коллекция** — 93 проверенных сценария четырёх уровней редкости.
- **Свободная лаборатория** — 3D-стол, переливание реактивов, управление температурой от −30 до 900 °C.

## Как устроена химия

- Уравнения уравниваются расчётом: решается система сохранения атомов и заряда.
- ΔH° считается по закону Гесса из стандартных энтальпий образования (25 °C, NBS/CRC).
- Замещение металлов — по стандартным электродным потенциалам, осадки — по таблице растворимости, бинарные соединения — по степеням окисления и электроотрицательности.
- Температурные пороги — ориентиры учебных сценариев, а не универсальные константы. Темп анимации ограничен; он не является расчётом химической скорости. При сильном нагреве водной среды показано упаривание, высокие значения относятся к режиму нагревателя.
- Каждый ответ помечен источником: «Проверенная реакция», «Выведено по правилам» или «Нет в базе» — игра не выдумывает то, чего не знает.

## GitHub Actions

- **CI** (`.github/workflows/ci.yml`) — на каждый push и pull request: тесты движка, сборка (артефакт `himlab-118`), затем браузерные тесты в Playwright.
- **Deploy to GitHub Pages** (`.github/workflows/pages.yml`) — на push в `main`: тесты, сборка и публикация `dist/` на GitHub Pages.

Чтобы публикация заработала, один раз включите Pages: **Settings → Pages → Build and deployment → Source: GitHub Actions**.

Прогресс игрока хранится в `localStorage` браузера.

## Обновлённая лаборатория

- Единое оформление в тёмной бирюзовой палитре, этапы опыта и паспорт вещества.
- Фотографические PBR-карты бетона (Poly Haven, CC0), процедурные фактуры металла и порошков; волны и мениск жидкости. Пять оригинальных GLB-моделей с внутренними стенками и отдельными деталями: колба, флакон, банка, стакан и микропипетка.
- Плавучесть лёгких металлов, тяжёлые капли ртути, постепенное растворение растворимых порошков и оседание осадков. Катализатор не расходуется.
- Движение и количество испускаемых частиц рассчитываются по времени, а не по кадрам.
- Управление камерой мышью, одним/двумя пальцами и клавиатурой (стрелки, +/−, Home); возврат камеры, пауза после переливания, облегчённая графика.
- Результаты на телефоне располагаются над сценой и не закрывают колбу.

### Границы научной модели

Массы, объёмы и концентрации задаются пользователем. Весы имеют виртуальный шаг 0,001 мг, пипетка — 1 мкл. Дозы сохраняются отдельно, в целых микрограммах / микролитрах; разные концентрации складываются по количеству вещества. Масса раствора и масса растворённого вещества не смешиваются. Атомные массы взяты из CIAAW 2024; для полимеров и элементов без стандартной атомной массы количество в молях не выдаётся. Давление и полное количественное равновесие не рассчитываются. Парные реакции в смеси из трёх веществ не являются расчётом конечного состава. Для одной необратимой реакции с полным молекулярным уравнением журнал вычисляет лимитирующий реагент, теоретический выход, остатки и ΔH = ξΔH°. Это предположение полного протекания, без растворимости, активности и кинетики. Тепловой эффект не равен изменению температуры колбы. pH рассчитывается только для воды, HCl/HNO₃ и NaOH/KOH при 25 °C, Kᵥ = 10⁻¹⁴, в идеальном растворе со следовыми индикаторами. Порог замерзания раствора −7 °C задан условно: температура зависит от состава и концентрации. Численный объём берётся из доз. Уровень жидкости для малых объёмов увеличен для видимости. Шкала колбы, число капель, цвет и время растворения иллюстративны. Остаток твёрдого реагента при доступном стехиометрическом расчёте учитывает лимитирующий реагент; для остальных сценариев расход иллюстративен. Данные плотности некоторых металлов используются только для отличия плавания от оседания в водной среде.

Кислород и водород бесцветны. В разложении 3 % H₂O₂ с MnO₂ или KI показываются пузырьки, а не высокая пена: для устойчивой пены требуется ПАВ. Для концентрированной серной кислоты не применяется модель кипения/замерзания воды.

## Дозирование и новые растворы

Каталог: 61 реагент и 118 элементов. Новые растворы включают индигокармин,
метиленовый синий, метилоранж, бромтимоловый синий, феноловый красный,
бромкрезоловый зелёный, KOH, CaCl₂, MgCl₂, ZnSO₄, AlCl₃, Na₂SO₄,
Na₂S₂O₃, K₃[Fe(CN)₆], KMnO₄, NaHCO₃, CH₃COONa, NH₄Cl, FeCl₂,
щавелевую и аскорбиновую кислоты. Это расширяемый каталог, не база всех
возможных растворов. Специальные реакции без модели помечаются «Нет в базе».

1. Выберите вещество в панели «Точное дозирование».
2. Выберите весы (мг вещества) или пипетку (мл раствора / воды).
3. Для раствора задайте концентрацию в моль/л.
4. «Задать количество» заменяет дозы этого вещества; «Добавить дозу»
   сохраняет предыдущие и добавляет новую. Опыт обновляется автоматически.
5. В «Балансе опыта» видны реальные введённые числа и доступный расчёт.

Для «Химического светофора» используйте индигокармин + глюкозу + NaOH.
Для «Синей бутылки» замените индигокармин метиленовым синим. Оба опыта
есть в витрине. После смешивания кнопка «Встряхнуть» возвращает окисленную
окраску. Цветовые стадии моделируются качественно: растворение O₂, расход
глюкозы, время переходов и число доступных циклов не рассчитаны. Сценарий
доступен при 5–60 °C и суммарной концентрации NaOH ≥ 0,01 моль/л.
